## About

**Disboard - The Boardtop World** was an official promotional website for *No Game No Life*.

The website was referenced in **Episode 1**, where Tet sends Sora and Shiro a message containing the URL. The original site hosted a **No Game No Life trivia quiz** in Japanese.

The original domain is no longer active and currently redirects to KADOKAWA.

This repository preserves the original website and its assets for **archival and historical purposes**.
